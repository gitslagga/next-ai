去年帮朋友对接技术方做Web3方向的数字藏品展示平台和DApp应用，踩过低价模板坑也遇到过交完定金拖几个月的，把自己的经验整理出来，给同样想做区块链应用、DApp、NFT数字藏品平台、联盟链资产系统的朋友参考。
首先要理清需求：是要单纯前端展示，还是需要写智能合约？接不接公链或联盟链？有没有后台KYC、实名认证、分账需求？需求模糊报价能从几万到几十万差很远。
选团队看三点：
① 有无同类案例——做过DApp或NFT平台的优先，别找只做企业官网的；
② 合同写清交付物——含源码、部署文档、后期Bug修复时长；
③ 沟通与响应——区块链项目迭代快，技术方能及时沟通很重要。
